EXPENSE_TRACKER
A simple Python-based Expense Tracker that helps users record and manage daily expenses. It allows users to add, view, update, and delete expenses, calculate total spending, and analyze expenses by category. The project uses CSV storage and basic Python concepts for easy and organized expense management.

Features
•	Add an expense
•	View all expenses
•	Calculate total expenses
•	Exit the program
•	Simple menu-based interface

Technologies Used
•	Python
•	Lists
•	Functions
•	Loops
•	Conditional statements
•	User input: python expense_tracker.py

Purpose
The purpose of this project is to practice basic Python programming concepts such as:
•	Variables
•	Lists
•	Functions
•	"if-else" statements
•	"for" and "while" loops
•	User input

Future Improvements
Some features that can be added in the future:
•	Save expenses permanently using files
•	Add expense categories
•	Add date and time
•	Delete an expense
•	Monthly expense summary
